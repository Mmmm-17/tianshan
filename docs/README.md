## 机器人简介：TS-1

```
                   ┌─────────────────┐
                   │  6 × SG90       │
                   │  机械抓夹        │  ← 根部旋转 / 抬升 / 俯仰 / 腕部微调 / 两指开合
                   └────────┬────────┘
                            │
        ┌───────────────────┴───────────────────┐
        │            STM32F103C8T6               │
        │   TIM1 ×4 + TIM4 ×2 → 六路舵机 PWM      │
        │   TIM2 / TIM3       → 四路电机 PWM      │
        │   SPI1              → PS2 接收器        │
        └───────────────────┬───────────────────┘
                            │
        ┌───────────────────┴───────────────────┐
        │  2 × DRV8833  →  4 × 金属壳 TT 马达     │
        │  4 × 麦克纳姆轮（X 型布局）              │
        └───────────────────────────────────────┘
                            │
        ┌───────────────────┴───────────────────┐
        │  2S 18650 7.4V                        │
        │   ├─ 直供 DRV8833 VM（动力）            │
        │   └─ 降压 5V（舵机）+ 3.3V（主控）       │
        └───────────────────────────────────────┘
```

**关键规格**

| 项 | 数值 |
|---|---|
| 收纳尺寸 | 290 × 195 × 210 mm 以内 |
| 展开尺寸 | 445 × 400 × 450 mm 以内 |
| 整车重量 | ≤ 2 kg |
| 驱动 | 2 × DRV8833 双 H 桥 |
| 执行器 | 4 × TT 马达（1:90）+ 6 × SG90 |
| 遥控 | PS2 手柄（2.4GHz 无线，SPI 类协议） |
